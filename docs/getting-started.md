# 上手手册：从刚创建的小程序到能跑起来

> 面向：刚在公众平台创建完小程序、拿到 AppID，第一次打开微信开发者工具。
> 预计耗时：15–25 分钟。全部是一次性操作。
> 你的 AppID 已写入项目（`wxd918e46bd873783c`），导入时不用再填。

---

## 第 1 步：安装并登录开发者工具

1. 打开 <https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
2. 下载 **稳定版 Stable Build → Windows 64**，一路默认安装。
3. 启动后**微信扫码登录**（必须是这个小程序的管理员或开发者微信号）。

## 第 2 步：导入项目

1. 首页点「+」→ **导入项目**。
2. 目录选：`D:\codex\号码管理助手`
3. AppID 会自动读出 `wxd918e46bd873783c`（读不到就手动粘一次）。
4. 「后端服务」选 **微信云开发**。
5. 点「导入」。

> 成功标志：左侧出现 `miniprogram/` 与 `cloudfunctions/`，模拟器显示首页。
> 此时首页大概率提示「云端未连接」或「身份校验未通过」——**正常**，后面几步解决。

## 第 3 步：开通云开发环境

**入口在哪？** 三个位置任选：

1. **工具栏**：模拟器上方那一排按钮里，找**云朵图标 +「云开发」**（通常在「上传」右侧，图标区靠右）。
2. **菜单栏**：`工具` → `云开发`（部分版本叫「云开发控制台」）。
3. **兜底**：浏览器打开 <https://cloud.weixin.qq.com/>，微信扫码登录，选你的小程序。

点击后会提示**开通** → 同意协议 → **创建环境**：

- 环境名称随便填，如 `jingcai`
- 套餐选 **免费/基础**（本项目数据量约 7MB，远低于免费额度）

创建完成后，云开发控制台会显示**环境 ID**（形如 `jingcai-3g8xxxx`）。
回到开发者工具，确认顶部/云开发面板用的是这个环境。

> 注意：**建集合、看数据库都在「云开发控制台」里**（点云开发按钮后弹出的新窗口/标签页），
> 不是你截图里那个 `Console / AppData` 调试面板——那是前端运行时数据，和数据库无关。

## 第 4 步：部署 9 个云函数（先部署，再初始化）

> **这一步不在云开发控制台做。** 控制台的「云函数」列表只显示"已部署到云端"的函数，
> 本地有目录 ≠ 已部署，所以你现在看到「暂无云函数 / 共 0 条」是正常的。
> 部署动作要在**开发者工具主窗口**里，对本地目录右键完成。

### 4.1 确认工具已连上你刚建的环境

1. 关掉（或最小化）云开发控制台窗口，回到开发者工具主窗口。
2. 左侧文件树找到 **`cloudfunctions`** 文件夹并展开。
3. 正常状态：该文件夹图标带**云朵标记**，里面的子目录也带小云朵。
4. 若不显示云朵：右键 `cloudfunctions` → **「切换云开发环境」**（或右键后选环境），
   在弹窗里选中你刚创建的环境（截图里叫 `cloud1`）。
5. 顶部工具栏的云开发入口旁，也应显示当前环境名。

### 4.2 逐个右键上传（9 次）

对下面**每一个**子目录单独右键：

```
cloudfunctions/
├── authCheck        ← 右键这个
├── initDb
├── syncDraws
├── queryDraws
├── importDraws
├── ticketService
├── queryTickets
├── checkTickets
└── aiChat
```

右键后菜单里有三个相似选项，**必须选中间那个**：

| 菜单项 | 能不能用 | 说明 |
|---|---|---|
| 上传并部署：所有文件 | ❌ | 会把本地 `node_modules` 一起传，体积巨大且可能失败 |
| **上传并部署：云端安装依赖（不上传 node_modules）** | ✅ **选这个** | 云端自己 `npm install`，本项目唯一的正确方式 |
| 仅上传 | ❌ | 只传文件不装依赖，函数会因找不到 `wx-server-sdk` 报错 |

### 4.3 等它跑完

- 右下角出现「上传成功」提示，通常 30 秒–2 分钟。
- 该目录右键菜单里会出现「已部署」字样。
- 若报「依赖安装失败」，多看一次日志：多半是网络抖动，**重试一次**即可。

### 4.4 回来核对

回到云开发控制台 → 云函数 → 刷新：

- 应用 9 个函数，状态「部署完成」
- 若只有 8 个，缺哪个回去补哪个

> **常见卡点**
> - 右键没有"上传并部署"菜单 → 第 4.1 步没做，工具还没绑定环境。
> - 提示无权限 → 当前登录微信不是该小程序的开发者/管理员。
> - 传完控制台仍 0 个 → 环境选错了（本地部署到了另一个环境），核对两处环境名是否一致。

## 第 5 步：用自己的 OpenID 打开第一道门

首次运行时还没有任何配置，只能靠环境变量识别你本人。

1. 开发者工具点**编译**，让小程序跑起来。
2. 进 **设置** 页 → 「身份」卡片会显示 **OpenID**（一长串字符），点一下复制。
3. 打开云开发控制台 → **云函数** → 点 `authCheck` → **配置** → **环境变量** → 新增：

   | 变量名 | 值 |
   |---|---|
   | `OWNER_OPENID` | 刚才复制的 OpenID |

4. 保存（环境变量即时生效，不必重新部署）。
5. 回到小程序设置页，点 **「重新校验身份」**。

> 成功标志：校验结果显示「已通过校验」。
> 这一步之后，你在小程序里看到的任何数据都只属于你自己。

## 第 6 步：一键初始化数据库

**不用手点 8 次建集合。** 设置页中部有「数据库初始化」卡片：

点 **「一键初始化数据库」**，它会：

1. 创建 8 个集合（已存在则跳过）
2. 写入 `app_config` 文档，并**把你的 OpenID 加进白名单**（从此不依赖环境变量）
3. 灌入 2 条规则版本（`ssq_2026_02_01`、`kl8_2025_12_30`）

弹窗会告诉你新建了几个、已存在几个。页面下方会列出**仍需手工创建的索引清单**。

> 若提示「SDK 不支持自动建集合」，按第 7 步的手工方式创建即可。

## 第 7 步：建索引 + 设权限（唯一必须手工的部分）

云开发控制台 → **数据库** → 逐个集合：

**权限**：点集合 → 权限设置 → 选 **「所有用户不可读写」** → 保存。
> 8 个集合全都要设。默认权限可能允许客户端直读，等于把库对外敞开。

**索引**：点集合 → 索引管理 → 新建索引

| 集合 | 索引 |
|---|---|
| `draw_records` | `game` 升序 + `issue` 降序（**唯一**）、`game` 升序 + `drawDate` 降序、`drawStatus` 升序 |
| `ticket_records` | `ownerOpenId` 升序 + `createdAt` 降序、`ownerOpenId` 升序 + `purchaseStatus` 升序、`ownerOpenId` 升序 + `idempotencyKey` 升序（**唯一**） |
| `ticket_checks` | `idempotencyKey` 升序（**唯一**）、`ticketId` 升序 + `checkedAt` 降序、`ownerOpenId` 升序 + `checkedAt` 降序 |
| `sync_logs` | `createdAt` 降序 |
| `ai_messages` | `sessionId` 升序 + `createdAt` 升序、`ownerOpenId` 升序 + `createdAt` 降序 |
| `ai_conversations` | `ownerOpenId` 升序 + `updatedAt` 降序 |

> 三个「唯一」索引别漏，它们是防重复写入的兜底（代码里另有幂等判断）。

## 第 8 步：拉一次官方数据

1. 底部「开奖」→ 右上「同步最新」。
2. 等 2–5 秒，列表应出现期号与号码。
3. 切到「快乐8」，再同步一次。

**报错对照**：
- `FETCH_FAILED` → 云函数出网被限制。改走 CSV：本地执行 `npm run import:draws -- 文件.csv`，控制台导入 `draw_records`。
- `AUTH_DENIED` → 第 5/6 步的白名单没生效，回设置页重新校验。
- 集合不存在 → 第 6 步没成功，用第 7 步手工建。

## 第 9 步：录一注号码，走完闭环

1. 「我的号码」→ 右下「＋ 新增号码」
2. 选彩种 → 填目标期号（7 位，如 `2026127`）→ 点号码 → 填倍数/金额 → 「保存为草稿」
3. 打开记录 → 「确认已购买」→ 填实际金额 → 确认（号码从此冻结）
4. 该期开奖并同步后 → 「一键核对」→ 看结果

## 第 10 步：配 DeepSeek 密钥（AI 助手需要）

1. 云开发控制台 → **云函数** → `aiChat` → **配置** → **环境变量**
2. 新增 `DEEPSEEK_API_KEY` = 你的 key
3. 保存后进入小程序「AI 助手」试一句「最新一期双色球开奖号码」

> 密钥只存云端。**不要**发到聊天、不要写进任何文件。怀疑泄露就去后台作废重建。

## 第 11 步：手机上预览

工具栏点 **「预览」** → 手机微信扫码。真机才能确认快乐8 那 80 个号码网格的实际手感。

## 常见报错对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示"未找到 app.json" | 导入目录选错 | 重新导入，目录必须是含 `project.config.json` 的那层 |
| `cloud.callFunction:fail -501000` | 未选云环境 / 函数未部署 | 检查环境，重新部署 |
| `PERMISSION_DENIED` | 集合权限没设成「所有用户不可读写」 | 逐集合改权限 |
| 首页一直"云端未连接" | `authCheck` 没部署成功 | 单独重新部署，看云函数日志 |
| 设置页没有 OpenID | 云开发没初始化 | 先完成第 3 步 |
| `initDb` 返回 AUTH_DENIED | 白名单还没包含你 | 先做第 5 步环境变量 |
| 同步 0 条 | 官方接口异常 | 看 `sync_logs` 集合的 error 字段 |
| 号码保存报 `NUMBERS_INVALID` | 号码数量/范围不对 | 双色球 6 红 1 蓝；快乐8 必须 10 个 |

## 你不需要做的事

- 不需要服务器、域名、备案
- 不需要 `npm install`（本项目零依赖）
- 不需要手改代码里的 AppID
- 不需要开通支付、订阅消息
